# Fontes no JavaFX

São muito semelhantes às do css normal, com algumas pequenas diferenças.

É possível aplicar os estilos aos elementos com a função **setStyle()** deles.

- **-fx-font-family**
  - system
  - arial
  - serif
  - sans-serif
  - Outras...

- **-fx-font-size**
  - 1pt, 2pt, 3pt, Npt, ...
  - 1px, 2px, 3px, Npx, ...
  - etc...

- **-fx-font-style**
  - normal
  - italic
  - oblique

- **-fx-font-weight**
  - normal
  - bold
  - bolder
  - lighter

## IMPORTANTE

As fontes utilizadas precisam estar instaladas no sistema operacional para que a customização funcione.

Algumas fontes tem mais chance de já virem instaladas em determinados sistemas, como a Arial no Windows.
