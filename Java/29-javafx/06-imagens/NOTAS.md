# Imagens no JavaFX

Existem duas classes para lidar com o carregamento de imagens no JavaFX: **Image** e **ImageView**.

**Image** é usada para **carregar a imagem**, enquanto **ImageView** é usada em seguida para exibi-la.

Existem também outras bibliotecas para lidar com imagens, como: **Java Advanced Imaging (JAI) (oferece suporte a mais opções de formatos de imagem), ImageIO e JavaFX Canvas (para formatos não suportados pelo JavaFX)**
