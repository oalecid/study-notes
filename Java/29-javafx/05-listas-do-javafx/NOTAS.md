# Listas do JavaFX

São semelhantes às outras listas do próprio Java, porém são projetadas especificamente para interfaces gráficas.

- **ListView**: Exibe uma lista vertical de itens, sendo altamente personalizável, permitindo definir aparência dos itens e comportamento ao selecionar itens
- **ObservableList**: Lista especial que permite observar alterações na lista quando elas ocorrem
- **FXCollections**: Kit de ferramentas para facilitar a manipulação de listas no JavaFX
