# Layouts

## Alguns tipos de itens para organizar o layout

- **VBox**: Para organizar elementos verticalmente
- **HBox**: Para organizar elementos horizontalmente
- **BorderPane**: Organiza elementos com base em um layout de cinco posições (top, bottom, left, right e center)
- **GridPane**: Organiza elementos em uma grade flexível de linhas e colunas

## Posicionamento (Pos)

O **Pos** do JavaFX fornece constantes para facilitar alinhamento (CENTER, TOP_LEFT, BOTTOM_RIGHT, etc.)
