# Programação Funcional

## Interfaces funcionais

São interfaces que contém apenas um método abstrato.

Com elas é possível usar também funções lambda.

Além disso, com o polimorfismo, é possível criar diferentes implementações para o mesmo método.

Por fim, existe uma anotação específica para esse tipo de interface, a **@FunctionalInterface**.
  - Isso faz com que a interface siga a estrutura correta de uma interface funcional, possuindo apenas um método abstrato

  - Entretanto, mesmo sem a anotação é possível criar interfaces funcionais, ela é apenas para forçar seguir o padrão correto
