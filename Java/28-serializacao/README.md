# Serialização

- A serialização em Java permite salvar informações de um objeto em um arquivo.

- Ela também serve para comunicações entre redes de computadores por meio de objetos

- Ela aumenta a compatibilidade entre APIs e bibliotecas, que podem usar serialização para trocar dados

- Em alguns casos, ela pode ser uma opção à um banco de dados, como para armazenamento de dados, cache, reduzir complexidade, etc. Porém ela não oferece tanta segurança
