# Sobre a lib de JSON

Para lidar com JSON foi utilizada uma biblioteca especial.

Ela foi salva no mesmo caminho das libs do JavaFX, em um arquivo **json-20230618**.

O comando para compilar e executar é semelhante aos que já estava sendo usados para o JavaFX, com a diferença que no **--add-modules** é preciso passar **org.json**
